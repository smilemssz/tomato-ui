# Settings page

Opened with the gear button on the title bar. Categories are switched with a segmented control. All values are saved automatically in the window's [cookies](/systems/cookies).

| Category | Content |
|---|---|
| General | UI opacity (30 to 100%), UI size (70 to 150%), Window corner (0 to 15, Window mode), Wallpaper switch, Wallpaper ID box and an Apply button that appears after you type an id |
| Controls | Hide and Show hotkey, Stack in Dock (max 6) |
| Theme | Main Color |
| System | Current mode, Clear saved data, Kill UI (asks for confirmation and calls `OnKill`), version |

## Wallpaper

1. Turn on the **Wallpaper** switch.
2. Type an asset id in the **Wallpaper ID** box.
3. Press **Apply** (it appears once the id differs from the applied one).

The Settings page is internal to the library and cannot be modified by user scripts.
