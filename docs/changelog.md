## 2.3 details

- Minimized windows no longer stack automatically. Drag a collapsed Dock window up next to another collapsed window or stack to join it.
- Instance Guard: `multi`, `unique` and `exclusive`.
- Cookies: device storage with automatic save and restore through `Save = "key"`.
